# Semana 6 — Limpieza y transformación de datos

**Enfoque:** preparación de datos · 3 horas

**Presentación:** [Abrir en Canva](https://www.canva.com/d/jSmz5aP2WDkcPxi) — diseño "Programación II – Semana 6", 24 diapositivas, con el código como captura de editor y sus salidas reales.

## Objetivo

Que el estudiante convierta un dataset con problemas de calidad en un dataset confiable y listo para el análisis, con un criterio claro y escrito para cada decisión: nulos, duplicados, texto, tipos de datos y variables nuevas.
