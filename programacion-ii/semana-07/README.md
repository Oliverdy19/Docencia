# Semana 7 — Automatización de procesos analíticos

**Enfoque:** eficiencia operativa · 3 horas

**Presentación:** [Abrir en Canva](https://www.canva.com/d/IYrxnO2rfZh_FjO) — diseño "Programación II – Semana 7", 24 diapositivas, con el código como captura de editor y sus salidas reales.

## Objetivo

Que el estudiante convierta un proceso analítico repetitivo en un script de Python que se ejecuta con un solo comando, procesa varios archivos por lotes, registra lo que pasó y entrega un resultado listo para usar.
