# Instrucciones para Claude

Este repositorio guarda el material docente del Prof. Oliver Díaz Ynoa (ITLA).

- Antes de crear o cambiar material, lee `REGLAS.md`: define la estructura de cada semana, de la presentación, del plan de clase y de las preguntas.
- El tema de cada semana sale de `programacion-ii/README.md` (cronograma). Si la semana está "Por definir", pregunta el tema antes de producir nada.
- Ejecuta todo el código antes de ponerlo en un plan, una diapositiva, una práctica o una pregunta; las salidas mostradas deben ser las reales.
- Las presentaciones se hacen en Canva copiando la plantilla "Programación II"; nunca edites la plantilla maestra.
- El repositorio es público: no subas parciales, claves de respuesta ni datos de estudiantes.
- Escribe en español dominicano neutro, con ejemplos del contexto local (ITBIS, RD$, telecom, colmado).
- Al terminar una semana, actualiza la tabla de estado en `programacion-ii/README.md`.
